Cabin: SIL Open Font License 1.1; see Cabin-OFL.txt.
Original variable font from the official Google Fonts repository:
https://github.com/google/fonts/blob/main/ofl/cabin/Cabin%5Bwdth%2Cwght%5D.ttf
Git blob SHA: 27f71b39824edcb34aada65f74f23c65a6cd32e2
Cabin-Regular.ttf and Cabin-Bold.ttf are static instances made with fontTools
at width 100 and weights 400 and 700. The original is Cabin-Variable.ttf.

Crimson Text: SIL Open Font License 1.1; see CrimsonText-OFL.txt.
Unmodified regular, bold, italic, and bold italic fonts from:
https://github.com/google/fonts/tree/main/ofl/crimsontext

Crimson Text is the body-font substitute for Cochineal. CTAN describes
Cochineal as a fork of the Crimson Roman, Italic, Bold, and BoldItalic fonts:
https://ctan.org/pkg/cochineal
